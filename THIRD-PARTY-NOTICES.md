## Ресурсы и модпаки

Прежняя иконка `Smile.ico` исключена из исходников и сборки.
Вместо неё используется авторская `KebuzLoncher.ico`, предоставленная
разработчиком для публикации вместе с лаунчером под его лицензией MIT.
Игровые обложки загружаются по URL из внешнего каталога. Отдельные файлы обложек
в исходники не включены; в документации есть скриншот интерфейса с ними.
Права на обложки и названия игр остаются у соответствующих правообладателей.

Моды, BepInEx, игровые файлы и другие содержимые модпаков не являются частью
MIT-лицензии лаунчера. Для каждого распространяемого мода отдельно проверьте
лицензию, право на повторную загрузку и обязательные уведомления. Самих
модпаков в проверяемом проекте нет, их лицензии этим аудитом не проверены.
Сборка модпака не даёт права перелицензировать чужие моды под MIT.

Этот файл описывает найденные зависимости и известные пробелы в происхождении
ресурсов. Авторство каждого участка существующего кода по истории Git не
проверялось.
